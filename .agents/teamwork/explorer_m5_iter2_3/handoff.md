## 2. Logic Chain

1. **Test Coverage Gap in Tier 1**:
   - `test_tier1_features.py` asserts route existence via list introspection (`assertIn("/health", routes)`).
   - This passes as long as FastAPI registers the path decorator `@app.get(...)`, regardless of whether calling the underlying function throws a runtime exception (`TypeError`, `KeyError`, etc.).
   - Adding tests that invoke `TestClient(app).get(...)` verifies the complete ASGI request-response cycle, including dependency injection, argument parsing, database/memory queries, schema serialization, and status code 200 emission.

2. **Root Cause Analysis & Fixes for `backend/main.py`**:
   - In `backend/main.py:430`, calling `hybrid_memory.search(q, limit=10)` raises `TypeError` because `HybridMemory.search` signature accepts `(query: str, top_k: int = 5, min_score: float = 0.0)`. Changing `limit=10` to `top_k=10` resolves the error.
   - In `backend/main.py:488–495`, `tools` contains dictionary schemas where the tool name can reside at `t.get("name")` or nested at `t.get("function", {}).get("name")`. Safely extracting `tool_name = t.get("name") or t.get("function", {}).get("name")` eliminates `KeyError: 'name'` and populates the permissions dictionary with all 18 tools.
   - When these two lines are patched, all 19 tests in `tests/test_challenger_m5_gateway_ws.py` pass cleanly (0 failures, 0 errors).

3. **Root Cause Analysis & Fixes for `backend/senses/crawl4ai_service.py`**:
   - When `bs4` is unavailable in `.venv`, `crawl4ai_service.py` relies on `_regex_html_to_markdown`.
   - Adding regex pattern matching for noise classes (`cookie|banner|advert|popup|modal|newsletter`) strips cookie banners and popups.
   - Updating heading regex to support unclosed tags (`<h1[^>]*>(.*?)(?:</h1>|(?=<[a-z/!]|\n|$))`) correctly extracts unclosed Markdown headings.
   - With this enhancement, all 31 tests in `tests/test_adversarial_m5_vision_mobile.py` pass cleanly (0 failures, 0 errors).

4. **Integration of Hardened Tier 1 Tests**:
   - Adding `test_f35_06_search_endpoint_contract`, `test_f35_07_permissions_endpoint_contract`, and `test_f35_08_health_endpoint_response` ensures `test_tier1_features.py` exercises the live endpoints.
   - On an unpatched backend, `test_f35_06` and `test_f35_07` reliably fail with HTTP 500, exposing the regressions.
   - On the patched backend, all three tests pass with HTTP 200 and expected payload content.
